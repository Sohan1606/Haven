# Haven — portfolio reel kit

## Positioning
Personal portfolio product / research demo, not an investment service or a finished live-trading AI. Not affiliated with Groww or any data provider. Use this positioning even if only posting the UI.

## 25-second vertical reel
Record at 1080×1920 where possible. Hide personal name, real balances, login details and browser notifications. Use a clearly identified demo profile. Browser responsive mode can show the mobile layout; do not imply a native Android APK exists.

- **0–3s / Hook:** Open the dashboard. Overlay: “What if market research felt less overwhelming?”
- **3–7s:** Tap “I'm available now.” Overlay: “A workspace built around your time.”
- **7–12s:** Open full-screen voice view, show mic and red hang-up. Overlay: “Call-style voice controls.” Keep microphone/provider limitations honest if discussing functionality.
- **12–17s:** Fetch historical research. Show date and source. Overlay: “Historical prices. Timestamped headlines.”
- **17–22s:** Open historical result including a loss / “Not approved for live use.” Overlay: “Test the idea. Show the downside.”
- **22–25s:** Show mobile + laptop layouts, separately. Overlay: “Haven · Portfolio project · GitHub in bio.”

Small persistent label: **“Research & paper-trading demo · No real orders.”**

Use transitions already in the UI rather than excessive zoom/shake edits. End with a question about design rather than an earnings promise. Only use music and assets you have rights to.
